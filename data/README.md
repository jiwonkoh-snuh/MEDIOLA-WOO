# Data files

All analysis and figure scripts in this repository read their inputs from this
`data/` directory, using the filenames listed below. Raw sequencing data are not
stored in this repository; they are deposited in GEO and EGA. Smaller processed
files generated in this study are provided here directly.

To reproduce a figure or table, place the files listed in the "Used by" column
into `data/` and run the corresponding script from the repository root.

---

| Dataset | Content |

| `EGAD50000002907` | Whole-exome sequencing |

and match the Data Availability statement of the manuscript.

## Reproducibility

The files in `data/` are the original analysis outputs used to produce the
published figures and tables. Re-running the scripts reproduces these values
exactly, with one exception. `gsea_hallmark_results.csv` comes from fgsea, whose
multilevel algorithm is stochastic, so adjusted P values can differ slightly
between runs and package versions even with a fixed seed. The deposited file is
the original output and should be treated as authoritative.
